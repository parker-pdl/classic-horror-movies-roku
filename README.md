# Classic Horror Movies by: ParkerDataLink.com

A Roku (SceneGraph / BrightScript) channel streaming 100+ public-domain horror,
sci-fi, silent, and creature-feature films from the Internet Archive, with a
Netflix-style browse UI and an updatable remote JSON feed.

See **INSTALL_AND_HOSTING.md** for sideloading, feed hosting on Cloudflare, and
the feed format. Channel content lives in `feed/feed.json` (also hostable at
`https://stream.parkerdatalink.com/roku/feed.json`).

Built by ParkerDataLink.com.
